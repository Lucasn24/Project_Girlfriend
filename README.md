# Project_Girlfriend — Tether

UI/UX design build for **Tether**, a platform for long-distance couples to stay emotionally connected across any distance or timezone. This is the chat page: the partner-to-partner thread, where an AI companion steps in and replies in your partner's voice whenever they're asleep or offline in another timezone. Design only — no chat functionality is wired up yet.

Built with React, TypeScript, Vite, and Tailwind CSS v4.

## Getting started

Requires [Node.js](https://nodejs.org/) 18+.

```bash
npm install
npm run dev
```

Then open the URL Vite prints (typically [http://localhost:5173](http://localhost:5173)).

## Other scripts

```bash
npm run build     # type-check and build for production
npm run preview   # preview the production build locally
npm run lint       # run oxlint
```
